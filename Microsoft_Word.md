Marked opens Microsoft Word (`.docx`) files as Markdown, and can export that Markdown back to DOCX.

## Round trip [round-trip]

Open a DOCX file and Marked converts styled text, such as headings and lists, to Markdown. Change tracking and comments become CriticMarkup, and highlights become `<mark>` tags. Export to DOCX to send the document back to Word, including CriticMarkup as change tracking.

See [Working with DOCX](Working_With_DOCX.html) for import and export details, headers and footers, math, and custom Word styles.
