[Traverse][traverse] includes a built-in **Stream to Marked** command. It appears in the export menu when Marked 2 or Marked 3 is installed.

## Stream to Marked [stream-to-marked]

Open the export menu (the button with an upward arrow) and choose **Stream to Marked**.

![Stream to Marked in the Traverse export menu][stream]

What Traverse sends depends on the outline:

- If you have added the **Type** attribute, Traverse sends the same Markdown it uses for Markdown export.
- If the outline uses **[Fountain](Fountain_for_Screenwriters.html)**, Traverse sends that text for preview.
- If neither is selected, Traverse sends a simple Markdown list.
