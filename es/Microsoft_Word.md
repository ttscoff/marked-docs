# <%= @title %>

Marked abre archivos de Microsoft Word (`.docx`) como Markdown y puede exportar ese Markdown de nuevo a DOCX.

## Ida y vuelta [round-trip]

Abra un archivo DOCX y Marked convierte el texto con estilo, como títulos y listas, a Markdown. El control de cambios y los comentarios pasan a ser CriticMarkup, y los resaltados, etiquetas `<mark>`. Exporte a DOCX para devolver el documento a Word, con CriticMarkup como control de cambios.

Consulte [Trabajar con DOCX](Working_With_DOCX.html) para los detalles de importación y exportación, encabezados y pies, matemáticas y estilos de Word personalizados.
