# appmenu reference — French (fr)

Ready-made French menu paths for the `{% appmenu … %}` tags. Translate only the **menu text**; leave shortcut tokens unchanged. Paths should match the localized app (`fr.lproj`).

Verify each path in the running localized Marked app before publishing.
