[Traverse][traverse] comprend la commande **Stream to Marked**. Elle apparaît dans le menu d'export lorsque Marked 2 ou Marked 3 est installé.

## Stream to Marked [stream-to-marked]

Ouvrez le menu d'export (le bouton avec une flèche vers le haut) et choisissez **Stream to Marked**.

![Stream to Marked dans le menu d'export de Traverse][stream]

Ce que Traverse envoie dépend du plan :

- Si vous avez ajouté l'attribut **Type**, Traverse envoie le même Markdown que pour l'export Markdown.
- Si le plan utilise **[Fountain](Fountain_for_Screenwriters.html)**, Traverse envoie ce texte pour l'aperçu.
- Si aucun des deux n'est choisi, Traverse envoie une simple liste Markdown.
