# <%= @title %>

FerventMind maps (`.fvmd`) open in Marked. Marked unzips the package. If `text.md` is inside, that file is the preview. If it is not, Marked builds an outline from `map.xml`.

## Outline from the map [outline-from-the-map]

Topic text becomes headings through the level set by **Headings through level** (2 by default). Deeper topics become nested bullets, so tasks at those levels keep a list checkbox. Notes become the section body. A finished task becomes a checked box, and a partial task shows its percent. Images are the files under `assets/`, without a filename caption.

## Display only visible topics [display-only-visible-topics]

**Display only visible topics**, in {% prefspane Apps %} under *FerventMind*, skips topics inside a folded branch when Marked builds that outline. It does not change a `text.md` the app already saved.

## Including a map [including-a-map]

Including a `.fvmd` uses **FerventMind files** under **Embed as Mermaid mind maps:** in {% prefspane Apps %}. On produces a Mermaid diagram of the visible or full tree, matching the checkbox above. Off embeds the map's `preview.png`. See [Embedding Mind Maps and Outlines](Embedding_Mind_Maps_and_Outlines.html).

## Open in Editor [open-in-editor]

**Open in Editor** ({% kbd cmd E %}) launches FerventMind.

# <%= @title %>

FerventMind-Karten (`.fvmd`) lassen sich in Marked öffnen. Marked entpackt das Paket. Liegt darin eine `text.md`, ist diese Datei die Vorschau. Andernfalls erstellt Marked eine Gliederung aus `map.xml`.

## Gliederung aus der Karte [outline-from-the-map]

Der Thementext wird zu Überschriften bis zu der Ebene, die **Überschriften bis Ebene** festlegt (Standard 2). Tiefere Themen werden verschachtelte Aufzählungen, sodass Aufgaben auf diesen Ebenen ihr Listenkästchen behalten. Notizen werden zum Abschnittstext. Eine erledigte Aufgabe wird ein angehaktes Kästchen, eine angefangene Aufgabe zeigt ihren Prozentwert. Bilder sind die Dateien unter `assets/`, ohne eine Bildunterschrift mit dem Dateinamen.

## Nur sichtbare Themen anzeigen [display-only-visible-topics]

**Nur sichtbare Themen anzeigen** unter *FerventMind* in {% prefspane Apps %} lässt Themen aus, die in einem eingeklappten Zweig liegen, wenn Marked diese Gliederung erstellt. Eine `text.md`, die das Programm bereits gespeichert hat, bleibt unverändert.

## Eine Karte einbinden [including-a-map]

Beim Einbinden einer `.fvmd` gilt **FerventMind-Dateien** unter **Als Mermaid-Mindmaps einbetten:** in {% prefspane Apps %}. Ist die Option ein, entsteht ein Mermaid-Diagramm des sichtbaren oder vollständigen Baums, passend zum Kontrollkästchen oben. Ist sie aus, wird die `preview.png` der Karte eingebettet. Siehe [Mindmaps und Gliederungen einbetten](Embedding_Mind_Maps_and_Outlines.html).

## Im Editor öffnen [open-in-editor]

**Im Editor öffnen** ({% kbd cmd E %}) startet FerventMind.
