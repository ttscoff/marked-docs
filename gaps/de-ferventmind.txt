# <%= @title %>

FerventMind maps (`.fvmd`) open in Marked. Marked unzips the package and previews the `text.md` FerventMind saved.

## Markdown in the map [markdown-in-the-map]

How that Markdown is written is set in FerventMind, under **Settings > Files And Export**, in the **Markdown** group. Marked shows the saved file as it is.

![FerventMind Files And Export][fm-export]

**Headings** sets how many levels stay headings. **Visible topics only** skips topics inside a folded branch. **Notes** and **Task checkboxes** control whether notes and tasks are written into that Markdown. These choices apply to Markdown export, Copy As, and the Markdown copy stored in every map for apps such as Marked. A map can override them under **Definitions • MAP**.

If an older map has no `text.md`, Marked builds an outline from `map.xml`: the title is heading 1, the next level is heading 2, and deeper topics become nested bullets. Notes become the section body. A finished task becomes a checked box, and a partial task shows its percent. Images are the files under `assets/`, without a filename caption.

## Including a map [including-a-map]

Including a `.fvmd` uses **FerventMind files** under **Embed as Mermaid mind maps:** in {% prefspane Apps %}. On produces a Mermaid diagram from the map. Off embeds the map's `preview.png`. See [Embedding Mind Maps and Outlines](Embedding_Mind_Maps_and_Outlines.html).

## Open in Editor [open-in-editor]

**Open in Editor** ({% kbd cmd E %}) launches FerventMind.

# <%= @title %>

FerventMind-Karten (`.fvmd`) lassen sich in Marked öffnen. Marked entpackt das Paket und zeigt die `text.md`, die FerventMind gespeichert hat.

## Markdown in der Karte [markdown-in-the-map]

Wie dieses Markdown geschrieben wird, legen Sie in FerventMind fest, unter **Settings > Files And Export**, in der Gruppe **Markdown**. Marked zeigt die gespeicherte Datei so, wie sie ist.

![FerventMind Files And Export][fm-export]

**Headings** legt fest, wie viele Ebenen Überschriften bleiben. **Visible topics only** lässt Themen in einem eingeklappten Zweig aus. **Notes** und **Task checkboxes** bestimmen, ob Notizen und Aufgaben in dieses Markdown geschrieben werden. Diese Wahl gilt für den Markdown-Export, für Copy As und für die Markdown-Kopie, die in jeder Karte für Programme wie Marked gespeichert wird. Eine Karte kann sie unter **Definitions • MAP** überschreiben.

Hat eine ältere Karte keine `text.md`, erstellt Marked eine Gliederung aus `map.xml`: Der Titel ist eine Überschrift der Ebene 1, die nächste Ebene ist eine Überschrift der Ebene 2, tiefere Themen werden verschachtelte Aufzählungen. Notizen werden zum Abschnittstext. Eine erledigte Aufgabe wird ein angehaktes Kästchen, eine angefangene Aufgabe zeigt ihren Prozentwert. Bilder sind die Dateien unter `assets/`, ohne eine Bildunterschrift mit dem Dateinamen.

## Eine Karte einbinden [including-a-map]

Beim Einbinden einer `.fvmd` gilt **FerventMind-Dateien** unter **Als Mermaid-Mindmaps einbetten:** in {% prefspane Apps %}. Ist die Option ein, entsteht ein Mermaid-Diagramm aus der Karte. Ist sie aus, wird die `preview.png` der Karte eingebettet. Siehe [Mindmaps und Gliederungen einbetten](Embedding_Mind_Maps_and_Outlines.html).

## Im Editor öffnen [open-in-editor]

**Im Editor öffnen** ({% kbd cmd E %}) startet FerventMind.
