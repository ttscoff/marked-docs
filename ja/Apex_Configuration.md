# <%= @title %>

これらのオプションは **Configure Apex** シートにあります。既定のプロセッサが **Apex（ベータ）** のとき、{% prefspane Processor %} から開きます。ここにある設定はすべて Apex だけに適用されます。数式、Critic Markup、ハッシュタグ、ファイルの取り込み、見出し ID は Marked のほかの設定のままです。

Apex とは何か、どの構文を扱うかは [Apex（ベータ）](Apex.html) を参照してください。

シートのチェックボックスは、Apex のメタデータファイルにある同じ設定より優先されます。ファイルパスは任意です。Marked が読めないパスは飛ばされ、プレビューはそのまま実行されます。

## ファイル [files]

CSL
: Apex が文献一覧を整形するときに使う Citation Style Language ファイル（`.csl`）。空のままにすると、文書またはメタデータファイルで指定したスタイルを使います。

文献一覧
: 1 つ以上の文献ファイル。BibTeX（`.bib`）、CSL JSON（`.json`）、CSL YAML（`.yml`、`.yaml`）を受け付けます。別のファイルを足すには **追加** をクリックします。Apex は引用を解決するとき、これらのファイルを参照します。

コンコーダンス
: 索引を作るときに使うコンコーダンスファイル（`.tsv`、`.txt`、`.csv`）を 1 つ以上。別のファイルを足すには **追加** をクリックします。

メタデータファイル
: Apex を実行する前に結合する外部メタデータファイル（`.yml`、`.yaml`、`.txt`、`.md`）。文書とファイルが同じキーを持つ場合は、文書側のメタデータが優先されます。このシートのチェックボックスは、メタデータファイルの値より優先されます。

## 構文 [syntax]

特記がないものは既定でオンです。

表
: 見出し行と区切り行を含むパイプ表。

脚注
: 参照脚注（`[^id]`）とインライン脚注。

定義リスト
: 用語と定義のリスト（`: definition`）。

上付き / 下付き
: `^super^` と `~sub~`。チルダ 1 つを下付きにしたくないときはオフにします。Marked の **~text~ を下線として描画** は別の設定で、下付きと衝突します。

取り消し線
: `~~deleted~~`。

URL とメールの自動リンク
: 裸の `https://` URL とメールアドレスをリンクにします。

フェンス付き div
: 節を `<div>` で包む `::: name` ブロック。

角括弧の span
: `[text]{.class}` のようなインライン属性 span。

アルファベットのリスト
: 数字に加えて、`a.` や `A.` で始まるリスト。

混在するリスト記号
: 1 つのリストで `*`、`+`、`-` を混ぜても、1 つのリストとして扱います。

HTML 内の Markdown
: HTML のブロックタグの中の Markdown を処理します。一部のマークアップはそれでも壊れます。

メタデータ変換
: `[%key]` プレースホルダを文書のメタデータで置き換えます。

## 表と画像 [tables-and-images]

グリッド表
: `+` と `|` で描くグリッド表。既定ではオフ。

緩い表
: パイプ表の先頭と末尾のパイプを省略できます。既定ではオン。

セルごとの配置
: セルの配置記号が列の配置を上書きします。既定ではオン。

画像のキャプション
: 画像のタイトル、タイトルがなければ代替テキストを、見えるキャプションにします。既定ではオン。

タイトルだけのキャプション
: キャプションには画像のタイトルだけを使い、代替テキストは無視します。既定ではオフ。**画像のキャプション** がオフのときは効果がありません。

## リンクと索引 [links-and-indexes]

Wiki リンク
: Apex が `[[wiki links]]` を変換します。既定ではオフ。オンのとき、その文書では Marked 自身のプレビュー「wiki リンクを変換」を飛ばし、Apex は Marked とは違う方法で対象ファイルを解決することがあります。既定の拡張子は Marked の wiki リンク設定から来ます。

Wiki リンク URL を正規化
: 生成した URL を小文字にし、アポストロフィを除き、文字でも数字でもない文字を置き換えます。既定ではオフ。**Wiki リンク** がオンのときだけ使えます。

索引の処理
: 索引マーカー（MultiMarkdown、mmark、Leanpub、textindex の各形式）を認識します。既定ではオン。

索引の出力を抑止
: マーカーは読みますが、生成した索引は出力しません。既定ではオフ。

## コールアウト（追加） [callouts-extra]

どちらも既定ではオフです。Obsidian と Bear のコールアウト（`> [!NOTE]`）は Apex の前に Marked が処理するため、ここでは制御しません。

Python-Markdown コールアウト
: `!!! note` 形式のコールアウト。

Quarto コールアウト
: Quarto の `::: {.callout-note}` ブロック。

## アクセシビリティ [accessibility]

どちらも既定ではオフです。

ARIA ラベル
: Apex が出力する HTML の構造を説明する ARIA 属性を追加します。

見出しアンカー
: 見出しに `id` だけを付ける代わりに、各見出しへ `<a>` アンカーを出します。
