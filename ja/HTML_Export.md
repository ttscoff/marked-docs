# <%= @title %>

Marked は**ライブプレビュー**からHTMLを書き出します --- 画面に表示されているのと同じレンダリング結果です。ブログやCMSに貼り付けるスニペットが必要なとき、あるいはスタイルや画像を埋め込んだ自己完結型の`.html`ファイル(どんなブラウザでも開けて、どこにでもホストできる)が必要なときにHTML書き出しを使いましょう。

典型的なワークフローは**まずプレビュー、それからHTML書き出し**です。Markedでドキュメントを開くかコンパイルし、テーマを選び、ライブプレビューで校正してから、マークアップが問題なければ書き出します。

## HTMLを取得する2つの方法 [two-ways-to-get-html]

### HTMLをコピー(スニペット) [copy-html-snippet]

**HTMLをコピー**は、プレビューのHTMLソースをクリップボードに置きます --- WordPress、Ghost、Squarespace、フォーラム、メールテンプレートなど、HTMLフラグメントを受け付けるあらゆるアプリにそのまま貼り付けられます。

* ギアメニュー → **HTMLをコピー**、またはプレビューにフォーカスがある状態で{% kbd shift cmd C %}
* **レンダリングされたbodyのHTML**をコピーします(`<html>`ラッパー付きの完全なドキュメントではありません)
* オプション: {% prefspane Export %}で**HTMLコピー時に画像を埋め込む**を有効にすると、ローカル画像をBase64エンコードして貼り付けたソース内で`data:` URLにできます

貼り付け先にすでに独自のスタイルシートがあり、コンテンツのマークアップだけが必要な場合は、HTMLをコピーが最適です。

### HTMLを保存(ファイル) [save-html-file]

**HTMLを保存**は、完全な`.html`ファイルをディスクに書き出します。

* 書き出し → **HTMLを保存**、{% kbd cmd S %}、または[書き出しパネル](Exporting.html#drawer)の**HTML**({% kbd shift cmd e %})
* 保存ダイアログでファイル名と保存場所を選択します
* ダイアログのアクセサリで書き出しオプションを設定します(下記参照)

HTMLを保存は、アーカイブ、単体で共有できるファイルの作成、結果をブラウザで直接開く場合に最適です。

## HTMLを保存のオプション [save-html-options]

HTMLを保存ダイアログには、書き出しプロファイルの選択と以下のオプションがあります:

![Save HTML options][savehtml]

**書き出しにスタイルを含める**

チェックすると、Markedは選択したプレビューテーマのCSSを、書き出したファイル内の`<style>`ブロックに埋め込みます。チェックボックス横のスタイルメニューから、組み込みテーマまたは[カスタムスタイル](Custom_Styles.html)を選べます。出力は`<!DOCTYPE html>`、`<head>`、そしてコンテンツを囲む`#wrapper` divを含む完全なHTMLドキュメントになり、プレビューで見たものと一致します。

チェックを外すと、Markedはレンダリングされたコンテンツのみを含む最小限のHTMLドキュメントを保存します(Markedのテーマ CSSは含まれません)。独自のスタイルを持つ別のシステムに貼り付けたりインポートしたりするための生のHTMLが欲しい場合に使用してください。

**単体HTML用にローカル画像を埋め込む**

**書き出しにスタイルを含める**が有効な場合、ローカル画像をBase64の`data:` URLとしてHTMLファイル内に埋め込むこともできます。これにより、別途`images/`フォルダを用意しなくても、メール送信・アップロード・ホスティングができる単一ファイルになります。

* ローカルドライブ上の**相対パスまたは絶対パス**で参照されている画像に対応します
* `file:///` URLは避けてください --- 確実に埋め込むことができません
* リモート画像(http/https)は、事前にダウンロードしない限り外部URLのままになります
* Base64埋め込みはファイルサイズが大きくなることがあります。ファイルサイズよりも可搬性が重要な場合に使用してください

**シンタックスハイライトのJavaScriptを含める**

{% prefspane Preview %}でシンタックスハイライトが有効な場合、このオプションはCDNからhighlight.jsのCSSとJavaScriptを追加し、書き出したファイルでもコードブロックの配色が保たれるようにします。書き出したHTMLでCDNリソースを読み込むには、インターネット接続が必要です。

**MathJaxまたはKaTeXのCDNリンクを含める**

プレビューで[MathJax](MathJax.html)またはKaTeXが有効な場合、保存するHTMLに対応するCDNスクリプトを含めることができ、ブラウザで数式がレンダリングされるようになります。シンタックスハイライトと同様、自分でスクリプトをホストしない限り、ファイルを閲覧する際にネットワークアクセスが必要です。

**CriticMarkupの書き出しタイプ**

[CriticMarkup](CriticMarkup.html)を含むドキュメントでは、書き出しで編集後のテキスト、元のテキスト、完全なマークアップのいずれを表示するかを選べます。

**書き出しプロファイル**

保存済みの[書き出しプロファイル](Exporting.html#export-profiles)を選択すると、好みのHTML書き出し設定(埋め込みスタイル、画像、シンタックスハイライト、数式)を一度に復元できます。

## 組み込みテーマとカスタムテーマでのスタイリング [styling-with-built-in-and-custom-themes]

**書き出しにスタイルを含める**がチェックされている場合、HTMLの見た目は**プレビュースタイル**によって決まります:

1. プレビューウインドウのスタイルメニューからスタイルを選ぶ(または{% prefspane Style %}でデフォルトを設定する)
2. ライブプレビューでタイポグラフィ、見出し、コードブロック、画像を確認する
3. 書き出しダイアログで同じスタイルを選択したままHTMLを保存する

Swiss、GitHub、Manuscriptをはじめ、Markedに組み込まれているすべてのテーマを埋め込むことができます。[カスタムスタイル](Custom_Styles.html)や[スタイルマネージャ](Custom_Styles.html)のスタイルも同様に機能します。

{% prefspane Style %}の**追加CSS**は、スタイルが埋め込まれている場合、HTML書き出しに含まれます。書き出された`<body>`には`mk-has-additional-css`クラスが付与され、Markedが書き換えた追加CSSのセレクタが一致するようになります。詳しくは[カスタムCSSの作成](Writing_Custom_CSS.html#additional-css-settings)を参照してください。

I> プレビュー専用のCSS(固定配置、ビューポートを使ったトリック、ダークモードの`@media screen`反転など)の一部は、Markedの外ではそのまま再現されないことがあります。公開前に保存したファイルをブラウザで開いて確認してください。

作成方法については、[カスタムCSSの作成](Writing_Custom_CSS.html)を参照してください。

## メタデータとMultiMarkdownヘッダー [metadata-and-multimarkdown-headers]

ソースファイル冒頭のMultiMarkdownメタデータは、HTML書き出しに影響することがあります:

* **`Title:`** --- 完全なHTMLドキュメントを保存する際に`<title>`要素に使用されます
* **`XHTML Header:`** / **`HTML Header:`** --- 書き出した`<head>`に追加のタグ(script、link、metaタグ)を挿入します
* その他のメタデータキーは、使用している[Markdownプロセッサ](Choosing_a_Processor.html)に従って処理されます

書き出し設定にメタデータを使うものの、他の出力ではキーを表示したくない場合は、HTMLコメントで囲んでください --- Markedはドキュメント内のどこにあってもコメント化されたメタデータを見つけて処理します。詳しくは[ドキュメントごとの設定](Per-Document_Settings.html)を参照してください。

## 複数ファイルドキュメント [multi-file-documents]

書籍や章ごとのファイルをまとめる場合は、[複数ファイルドキュメント](Multi-File_Documents.html)を使用してください。Markedは結合されたドキュメントをプレビューし、コンパイル結果から1つのHTMLファイルを書き出します。含まれるファイルにはソースパスを示すHTMLコメントが付けられるため、どの章がどのセクションに寄与しているかを確認する際に役立ちます。

## 他のアプリケーションへの貼り付け [pasting-into-other-applications]

| 貼り付け先 | 推奨する方法 |
| :-- | :-- |
| 独自テーマを持つブログ / CMS | **HTMLをコピー**(スニペット、MarkedのCSSは埋め込まない) |
| 静的サイトやアーカイブ | **書き出しにスタイルを含める**を有効にして**HTMLを保存** |
| メールやファイル共有(添付ファイル1つ) | **ローカル画像を埋め込む**を有効にして**HTMLを保存** |
| WordPress、Ghost、Notionなど | **HTMLをコピー**。エディタがローカルパスを解決できない場合は**HTMLコピー時に画像を埋め込む**を有効にする |
| コードエディタでのさらなる編集 | スタイルを埋め込まずに**HTMLを保存**するか、スニペットをコピーして手動でラップする |

貼り付け先のアプリがHTMLソースではなく書式付きテキストを受け付ける場合は、[リッチテキストをコピー](Exporting.html#rtfexportoptions)(ギアメニュー)が代わりの選択肢になります。
