# <%= @title %>

**Marked Share** は、Marked のオンライン出版サービス ([share.markedapp.com](https://share.markedapp.com)) です。 Mac を一度接続し、画像とオプションの閲覧モード ハイライトを含むフロント ドキュメントを **TextPack** として公開します。リンクを知っている人は誰でも Web 上でドキュメントを表示できます。

この機能は、macOS **共有拡張機能** (システムの共有メニュー) とは別のものです。他のアプリから Marked にファイルまたは選択内容を送信する方法については、[Using the Share Extension](Share_Extension.html) を参照してください。

## アカウントを接続します [connect-your-account]

最初の公開の前に、Marked を共有アカウントに接続します。

1. {% appmenu ファイル, 公開, アカウントを接続… %} を選択します。
2. Marked はデフォルトのブラウザを開き、share.markedapp.com にサインインします。
3. 接続を承認すると、ブラウザは安全なログイン リンクを含む Marked に戻ります。ダイアログに表示されるアカウントラベルを確認します。

Marked は、この Mac の macOS キーチェーンに API トークンとデバイス キーを保存します。資格情報はログやクラッシュ レポートに書き込まれません。

切断するには、{% appmenu ファイル, 公開, アカウントを切断… %} を選択します。公開されたドキュメントはオンラインに残ります。必要に応じて、share.markedapp.comでいつでもアクセスを取り消します。

## ドキュメントを公開する [publish-a-document]

プレビューでドキュメントを開いた状態で、{% appmenu ファイル, 公開, 公開… %} を選択します。

初めてドキュメントを公開すると、Marked によって小さなオプション シートが表示されます。

- **タイトル** — 共有上に表示されます (デフォルトは拡張子を除いたドキュメント名です)。
- **公開設定** — 非公開、非公開、または公開。新しいパブリッシュはデフォルトで **非公開** (リンクによってアクセス可能、公開リストには掲載されていません) になります。
- **読書スタイル** — 社説、原稿、スイス、コントラスト、タイプライター、または **なし**。可能な場合は、ドキュメントのプレビュー スタイルをデフォルトにします。 Share はこれを提案として使用します。読者はそれをオーバーライドできます。推奨スタイルなしで公開するには、[**なし**] を選択します。
- **ハイライトとコメントを含める** — TextPack に読書モードのハイライトを埋め込みます。ドキュメントにハイライトがある場合、デフォルトはオンになります。
- **他の人によるリミックスを許可** — 有効にすると、閲覧者は共有でドキュメントをフォークできます。

Marked は、バックグラウンドで TextPack (Markdown、アセット、およびオプションの `highlights.json`) を構築し、アップロードして、この Mac 上の共有 URL を記録します。

### 既存のパブリッシュ [update-an-existing-publish] を更新します

ドキュメントが共有にリンクされると、メニュー項目は **公開…** ではなく **公開ドキュメントの更新** となります。新しい TextPack バージョンをアップロードするには、これを選択します。 Marked はサーバーのコンテンツ ハッシュを送信するため、別の Mac または Web からの同時編集が検出されます。

他のユーザーが最初に共有上のドキュメントを更新した場合、Marked は、この Mac のバージョンで **上書き**するか、**Web で開く**、または **キャンセル**するかを尋ねます。

## 公開後 [after-publishing]

公開が完了すると、Marked は成功を確認し、次のことを提供します。

- **共有リンクをコピー** — {% appmenu ファイル, 公開, Share リンクをコピー %}
- **ウェブで開く** — {% appmenu ファイル, 公開, Web で開く %}

これらのコマンドは、リンクされたパブリッシュ レコードがある場合、フロント ドキュメントに適用されます。

## 公開ドキュメントウィンドウ [published-documents-window]

{% appmenu ファイル, 公開, 公開済みドキュメント… %} を選択すると、この Mac から公開され、共有アカウントから同期されたドキュメントのリストが開きます。

エントリごとに次のことができます。

- Marked がまだディスク上にローカル ファイルへのリンクを持っている場合は、ローカル ファイルを **開きます**。
- ローカル ファイルがない場合は、TextPack を **インポート**します (任意の場所に保存し、Marked で開きます)。
- **Web で開く**、または共有 URL の **リンクをコピー**。
- **ローカル パスがわかっている場合は、**Finder に表示**します。
- **忘れ** は、オンライン ドキュメントを削除せずに、この Mac からレコードを削除します。

接続すると、共有からリストが更新されます。オフラインまたは切断されている場合、Marked にはキャッシュされたレコードが表示され、再接続を求めるメッセージが表示される場合があります。

## 公開できるもの [what-you-can-publish]

Marked がレンダリングできる以下のドキュメントを公開できます。

- 保存された Markdown およびテキスト ファイル
- 一時的なプレビュー (クリップボード、ストリーミング、または未保存のドキュメント)
- TextBundles およびその他のサポートされている形式

ドキュメント ウィンドウごとに一度に実行される公開操作は 1 つだけです。アップロードの進行中、メニュー項目は無効になります。

## ヒント [tips]

- 公開には、プレビューで参照される画像が含まれます。非常に大きなバンドルはアップロード前に拒否される場合があります。サイズ制限に達した場合は、埋め込みアセットを削減します。
- TextPack でエクスポートされたハイライトは、Marked のハイライト JSON 形式を使用します。ハイライトの作成とエクスポートについては、[Reading Mode](Reading_Mode.html) を参照してください。
- Marked Share は、Direct、Mac App Store、Setapp、および Marked Pro ビルドで利用できます。公開するために別のサブスクリプションは必要ありません。
