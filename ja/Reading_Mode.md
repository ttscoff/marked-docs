# <%= @title %>

読書モードでは、長い文書の中でも位置を維持し、現在のブロックに焦点を当て、永続的なハイライトを保存できます。

## 読書モードに入る [entering-reading-mode]

{% appmenu Preview, Reading Mode %} を選択するか、{% kbd ctrl opt r %} を押します。 Speed Read が実行中の場合、Marked は読み取りモードに入る前にそれを停止します。

現在の段落、見出し、リスト項目、画像、コード ブロック、表、またはその他の読み取り単位は左マーカーを受け取ります。キーボード ナビゲーションはブロック間をスムーズに移動し、現在のユニットをプレビューの上 3 分の 1 付近に保ちます。手動でスクロールすると、ページをスナップせずにフォーカスが再設定されます。

## ナビゲーションと再開 [navigation-and-resume]

読書モードがアクティブな間:

- {% kbd j %} または {% kbd down %}: 次の読み取り単位に移動します。
- {% kbd k %} または {% kbd up %}: 前の読み取り単位に移動します。
- {% kbd h %}: 選択内容を強調表示するか、テキストが選択されていない場合は現在のユニットの強調表示を切り替えます。

Marked は、各ドキュメントの現在の読み取り位置を保存します。保存された位置が現在のビューと異なる場合、読み取りモードに入ると、次の 2 つの選択肢が表示されます。

- **再開** は、保存された読み取り位置に戻ります。
- **ここから開始** では、現在プレビューに表示されている読み取り単位が使用されます。

## フォーカスモード [focus-mode]

プレビューの上部にあるフォーカス モード ツールをクリックすると、現在の読み取り単位を除くすべてのブロックが暗くなります。フォーカス モードは、ナビゲーション中に現在のユニットに従います。ツールをもう一度クリックして他のブロックを復元するか、読み取りモードを離れてフォーカス モードを自動的にクリアします。

## ハイライトの作成と編集 [creating-and-editing-highlights]

テキストを選択し、{% kbd h %} を押して、インライン マーカーのハイライトを作成します。何も選択しないで、{% kbd h %} を押して現在の読み取り単位全体を強調表示するか、もう一度押してその単位の強調表示を削除します。最初の強調表示では、Marked が CriticMarkup を作成するときに使用する署名の入力を求められます。署名は{% prefspane Preview %}で変更できます。

### 選択ポップアップ

テキストを選択すると、行の中央にアイコン ボタンが配置された選択ポップアップが表示されます。

- **ハイライター** はインライン ハイライトを作成します (または、自動ハイライトがオンの場合は **X** により最後の自動ハイライトが削除されます)。
- **コメント** は、ハイライトのメモを追加または編集するためのダイアログを開きます。選択内容がまだ強調表示されていない場合は、Marked が最初に選択内容を強調表示します。

**選択時に単語数を表示** が有効になっている場合、ポップアップには選択された単語数も表示されます。

### コメントを強調表示する [highlight-comments]

コメントは署名とは別のものです。署名はハイライトを表します。コメントはそれに関するメモです。

選択ポップアップのコメント アイコンからコメントを追加または編集するか、強調表示された項目を Control キーを押しながらクリックして、**コメントの追加…** または **コメントの編集…** を選択します。ハイライトを削除せずにメモを削除するには、[**コメントの削除**] を選択します。

コメント付きのハイライトには小さなインジケーター ドットが表示されます。コメント サイドバーが表示されている場合 (**プレビュー > コメントの表示**)、読書モードのハイライト コメントが、CriticMarkup および他のドキュメント コメントと並んで、親ハイライトへの接続線とともに表示されます。

### 自動ハイライト

プレビューの上部にあるハイライト ツールをクリックすると、テキストを選択すると自動的にハイライト表示されます。選択ポップアップのハイライトをクリックして最後の自動ハイライトを元に戻すか、上部のハイライタ ツールを再度クリックして自動ハイライトをオフにします。

インライン ハイライトでは、開始ハンドルと終了ハンドルをポイントまたは選択すると、ハンドルが表示されます。いずれかのハンドルをドラッグして、ハイライト表示された範囲を拡張または縮小します。変更は自動的に保存され、ドキュメントを更新するか再度開くと復元されます。

ハイライトをクリックしてフォーカスし、Delete キーまたは Backspace キーを押して削除します。 Control キーを押しながらハイライトをクリックして **共有...** を選択すると、ドキュメント タイトルとハイライト表示されたテキストが表示された macOS 共有シートが開きます。**コメントを追加...** / **コメントを編集...** してメモを添付するか、**コメントを削除**してメモをクリアします。

**読書モードがオフのときにハイライトを表示** 設定は、モードを終了した後も保存されたハイライトを表示し続けるかどうかを制御します。

## ハイライトのエクスポート [exporting-highlights]

**[プレビュー] > [ハイライトのエクスポート…**] を選択するか、読書モード ツールバーの [ハイライトのエクスポート] ツールをクリックします。形式: Markdown、HTML (現在のプレビュー スタイル)、プレーン テキスト、CSV (読み取り互換、**Note** 列にコメント、**Signature** に署名)、および JSON (各ハイライトに `comment` フィールドが含まれます)。

HTML エクスポート ネストは、強調表示された各パッセージの下にあるブロック引用符としてコメントを強調表示します。

JSON 形式は Marked の交換ファイルです。これを Markdown ドキュメントの横に `Document.markedhighlights.json` として保存するか、TextBundle をエクスポートするときに自動的に含めます。

## ハイライトのインポート [importing-highlights]

**[プレビュー] > [ハイライトのインポート…**] を選択し、Marked ハイライト JSON ファイルを選択します。 ID によってハイライトを結合: 新しい ID が追加され、一致する ID が更新され、ファイルにない既存のハイライトは残ります。

`highlights.json` を含む TextBundle を開くと、Marked によってそれらのハイライトが自動的に結合されます。 TextBundle が開いている間、Marked はハイライトとコメントの変更をバンドル内の `highlights.json` に保存します (`text.md` は変更しません)。

## TextBundle のハイライト [textbundle-highlights]

**Save TextBundle** で、**ハイライトを含める** を有効にして、`highlights.json` をバンドル (または TextPack) に埋め込みます。バンドルを共有すると、共同作業者が Marked でバンドルを開いて、結合されたハイライト セットを保持できるようになります。

## CriticMarkup アクション [criticmarkup-actions]

ハイライトのエクスポートとインポートとは別に、プレビュー メニューには、保存されたハイライトに対して 2 つの CriticMarkup アクションが用意されています。

- **ハイライトを CriticMarkup としてコピー** は、ソース ファイルを変更せずに、すべてのハイライトを CriticMarkup 形式でコピーします。
- **ドキュメントにハイライトを挿入...** は確認を求め、明確に一致するソース テキストを CriticMarkup でラップします。 Marked は、欠落している一致、重複している一致、または重複している一致をスキップし、結果を報告します。

署名とコメントがある場合、生成されたマークアップは <code>{=<span>=</span>highlighted text==}{&gt;&gt;signature: comment&lt;&lt;}</code> を使用します。コメントのみの場合、Marked は <code>{=<span>=</span>highlighted text==}{&gt;&gt;comment&lt;&lt;}</code> を使用します。署名のみの場合は、<code>{=<span>=</span>highlighted text==}{&gt;&gt;signature&lt;&lt;}</code> を使用します。どちらも指定しないと、Marked は <code>{=<span>=</span>highlighted text==}</code> マーカーのみを作成します。

## ハイライトの印刷 [printing-highlights]

デフォルトでは、印刷または PDF として保存するときに、読み取りモードのハイライトが含まれます。現在の出力用に変更するには、印刷シートで **読み取りモードのハイライトを含める** を使用します。 {% prefspane Export %} の一致設定は、今後の印刷ジョブと PDF ジョブのデフォルトを制御します。
