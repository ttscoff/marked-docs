### レイアウトとタイポグラフィ [layout-and-typography]

プレビューのテキスト幅を制限する
: スライダーを使ってプレビュー本文の最大幅を（ピクセル単位で）設定します。

段落内の自動ハイフネーション
: 単語がハイフネーションによって自動的に改行されるようにします。

見出しや段落での「ウィドウ（追い出し）」を防止する
: 見出しや段落の最後の2つの単語の間に改行禁止スペースを強制的に挿入し、単語が単独で次の行に折り返されるのを防ぎます。

タイポグラフィ的に正しい引用符・句読点を生成する
: SmartyPantsを使用して、スマート引用符、省略記号への変換、その他のタイポグラフィ機能を適用します（MultiMarkdown）。

脚注マーカーを角括弧で囲む
: チェックすると、脚注マーカーにMultiMarkdownの標準フォーマット（[1]）を使用します。チェックを外すと角括弧を取り除きます。

拡張子に対してアウトラインを有効にする
: リストされた拡張子を持つファイルに対して、自動的にアウトラインモードをオンにします。

APAスタイルを使用する
: デフォルトの10進数フォーマットの代わりに、APAスタイルのアウトラインを使用します。

逐語（コード）ブロックを詩として表示する
: チェックすると、タブインデント、フェンス、またはインクルードされたコードが、コードブロックではなく詩として表示されます（シンタックスハイライトなし、テーマに応じた特別なスタイル）。

テーマによるコードブロック内のテキスト折り返しを許可する
: チェックすると、テーマが`pre>code`ブロック内でのテキスト折り返しを行うことを許可します。チェックを外すと、水平方向のオーバーフローは常にスクロールになります。

常にコードを折り返す
: テーマの設定にかかわらず、コードブロックを強制的に折り返します（テーマの折り返し動作を上書きします）。

RTLテキストを検出してスタイルを適用する
: ドキュメント内の要素ごとに言語を検出し、右から左（RTL）のテキストに適切なスタイルを適用します。

### テーマ [theme]

スタイルを管理
: [スタイルマネージャ](Style_Manager.html)ウィンドウを開きます。ドライブ上のCSSファイルを追加すると、スタイルピッカーメニューに表示されるようになります。`Add New Style`ボタンを使うか、このウィンドウにCSSファイルをドラッグしてください。ドラッグして順序を変更でき、チェックボックスでスタイルの有効・無効を切り替えられます。

その他のテーマ
: オンラインのテーマギャラリーを開いて、追加のスタイルを閲覧・インストールできます。

デフォルトスタイル
: ここで選択したスタイルは、[メタデータでドキュメント固有のスタイルが指定](Per-Document_Settings.html)されていない限り（例：「Marked Style: Grump」）、すべての新しいウィンドウで読み込まれます。

CSSの変更を追跡する
: これを有効にすると、Markedは現在のスタイルのディスク上の変更を監視し、カスタムスタイルの編集やWeb開発に役立ちます。

追加CSS
: ここに追加したCSSは、各テーマの通常のスタイルシートの後に付加されます。これは部分的なオーバーレイであり、テーマ全体を置き換えるものではありません。
: Markedはこのフィールド内のセレクタを書き換えます（例えば、印刷用ルールには`body.mkprinting #wrapper …`を使用する必要があります）。サイズや妥当性のチェックはありません --- 詳しくは[カスタムCSSの作成](Writing_Custom_CSS.html#additional-css-settings)を参照してください。
: これはすべてのドキュメントとすべてのスタイルに適用され、スタイルを含めたHTMLエクスポートにも適用されます。条件に応じて特定のドキュメントにカスタムCSSを適用したい場合は、{% prefspane Processor %}の「カスタムルール」を使用してください。

### スクリプトを含める [include-scripts]

シンタックスハイライト
: コードブロックに対してhighlight.jsの[シンタックスハイライト](Syntax_Highlighting.html)を有効にします。ドロップダウンからテーマを選択してください。
: **言語が指定されている場合のみ**がチェックされている場合、シンタックスハイライトは言語が指定されたフェンス付きコードブロックにのみ適用されます。

MathJaxを有効にする
: MathML数式を表示するために[MathJax](MathJax.html)を読み込みます。ドロップダウンから**ローカル**（同梱版）または**CDN**を選択してください。
: **追加パッケージ**をクリックすると、追加のMathJaxパッケージ（例えばPhysicsやChemistry）を含めるためのシートが開きます。
: **詳細設定**をクリックすると、カスタムMathJax設定用のシートが開きます。

KaTeXを有効にする
: MathJaxの代替として[KaTeX](MathJax.html#katex)を読み込みます。MathJaxとKaTeXのどちらか一方のみを選択できます。

数式に番号を振る
: 該当する場合、Markedはレンダリングされた数式に図番号を追加します。番号の位置として**左側**または**右側**を選択してください。MathJaxを使用している場合は、**AMSのみ**を選択してAMS数式のみに番号を振ることもできます。

Mermaid
: CDNから[mermaid.js](https://mermaid.js)を読み込み、Markdown形式の図表作成を可能にします。ドキュメントが更新されるたびにMermaid図を描画するために必要なフックは自動的に組み込まれます。

図表のパンとズーム
: Mermaid図が存在する場合、{% kbd cmd %}-スクロールでズーム、クリック＆ドラッグでパンができるようになります。
