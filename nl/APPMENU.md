# appmenu reference — Dutch (nl)

Ready-made Dutch menu paths for the `{% appmenu … %}` tags. Translate only the **menu text**; leave shortcut tokens unchanged. Paths should match the localized app (`nl.lproj`).

Verify each path in the running localized Marked app before publishing.
