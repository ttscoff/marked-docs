# appmenu reference — Portuguese (Brazil) (pt-BR)

Ready-made Brazilian Portuguese menu paths for the `{% appmenu … %}` tags. Translate only the **menu text**; leave shortcut tokens unchanged. Paths should match the localized app (`pt-BR.lproj`).

Verify each path in the running localized Marked app before publishing.
