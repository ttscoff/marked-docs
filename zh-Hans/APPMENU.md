# appmenu reference — Simplified Chinese (zh-Hans)

Ready-made Simplified Chinese menu paths for the `{% appmenu … %}` tags. Translate only the **menu text**; leave shortcut tokens unchanged. Paths should match the localized app (`zh-Hans.lproj`).

Verify each path in the running localized Marked app before publishing.
