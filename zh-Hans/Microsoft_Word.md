Marked 把 Microsoft Word（`.docx`）文件作为 Markdown 打开，也可以把这份 Markdown 再导出为 DOCX。

## 来回转换 [round-trip]

打开 DOCX 文件后，Marked 会把标题、列表等带样式的文字转成 Markdown。修订和批注变成 CriticMarkup，高亮变成 `<mark>` 标签。导出为 DOCX 即可把文稿送回 Word，CriticMarkup 会变成修订。

导入和导出、页眉和页脚、公式以及自定义 Word 样式，请参阅[使用 DOCX](Working_With_DOCX.html)。
