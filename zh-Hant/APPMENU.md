# appmenu reference — Traditional Chinese (zh-Hant)

Ready-made Traditional Chinese menu paths for the `{% appmenu … %}` tags. Translate only the **menu text**; leave shortcut tokens unchanged. Paths should match the localized app (`zh-Hant.lproj`).

Verify each path in the running localized Marked app before publishing.
