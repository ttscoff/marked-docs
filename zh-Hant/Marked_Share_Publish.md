# <%= @title %>

* * Marked Share * *是Marked在⟦P0的線上發佈服務⟧。連接Mac一次，然後將正面文件發佈為* * TextPack * * ，其中包含圖像和可選的閱讀模式亮點。任何擁有連結的人都可以在網路上查看文件。

此功能與macOS * *分享擴充功能* * （系統分享選單）分開。如⟧需從其他應用程式傳送檔案或選擇至「已標記」，請參閱⟦P0。

# #連結您的帳戶[connect-your-account]

在首次發佈前，請將「已標記」連結至你的分享帳戶：

1.選擇{% appmenu 檔案, 發佈, 連接帳號… %}。
2. Marked會開啟預設瀏覽器，以登入share.markedapp.com。
3.核準連線後，瀏覽器會以安全登入連結返回「已標記」。 確認對話方塊中顯示的帳戶標籤。

Marked將API權杖和裝置金鑰儲存在此Mac的macOS金鑰鏈中。認證不會寫入日誌或當機報告。

若要中斷連線，請選擇{% appmenu 檔案, 發佈, 斷開帳號… %}。已發佈的文件會維持在線上；如有需要，可隨時在share.markedapp.com撤銷存取權限。

# #發佈文件[publish-a-document]

在預覽中開啟文件後，選擇{% appmenu 檔案, 發佈, 發佈… %}。

首次發佈文件時，「已標記」會顯示一個小選項表：

- * *標題* * —顯示在「分享」上(預設為文件名稱，不含副檔名)。
- * *可見性* * —私密、未發佈或公開。 新發佈的內容預設為* *未發佈* * （可透過連結存取，未公開發佈）。
- * *包含摘要和評論* * —在TextPack中嵌入閱讀模式摘要。 當文件有醒目提示時，預設為開啟。
- * *允許其他人混音* * —啟用後，檢視者可以在「分享」上分叉文件。

Marked會在背景(Markdown、資產和可選的`highlights.json`)中建立TextPack ，上傳並記錄此Mac上的共用URL。

# # #更新現有發佈[update-an-existing-publish]

文件連結至「分享」後，選單項目會顯示* *更新已發佈文件* * ，而非* *發佈… * *。選擇它以上傳新的TextPack版本。Marked會傳送伺服器的內容雜湊，以便偵測來自另一臺Mac或網路的同時編輯。

如果其他人先在「分享」上更新文件，「已標記」會詢問是否要使用此Mac的版本* *覆蓋* *、* *在網頁上開啟* *或* *取消* *。

# #發佈後[after-publishing]

發佈完成後， Marked會確認成功並提供：

- * *複製分享連結* * — {% appmenu 檔案, 發佈, 拷貝 Share 連結 %}
- * *在網頁上開啟* * — {% appmenu 檔案, 發佈, 在網頁中開啟 %}

當正面文件有連結的發佈記錄時，這些命令會套用到正面文件。

# # Published Documents窗口[published-documents-window]

選擇{% appmenu 檔案, 發佈, 已發佈文件… %}以開啟從此Mac發佈的文件清單，並從您的「分享」帳戶同步。

對於每個參賽作品，您可以：

- * *開啟* *已標記的本機檔案，但磁碟上仍有該檔案的連結。
-在沒有本地文件時* *匯入* * TextPack （將其保存在任何地方並在Marked中打開）。
-分享網址為* *在網頁上開啟* *或* *複製連結* *。
- * *當已知本機路徑時，在Finder中顯示* *。
- * *忘記* *會從此Mac移除記錄，而不會刪除線上文件。

連線後，清單會從「分享」重新整理。如果您處於離線狀態或已中斷連線，「已標記」會顯示快取記錄，並可能會提示您重新連線。

# #你可以發佈的內容[what-you-can-publish]

您可以發佈「標記」可呈現的任何文件，包括：

-已儲存的Markdown和文字檔案
-暫時性預覽(剪貼簿、串流或未儲存的文件)
- TextBundle和其他支持的格式

每個文件視窗一次只能執行一個發佈作業；上傳時會停用選單項目。

# # Tips [tips]

-發佈包括預覽引用的影像。 上傳前可能會拒絕非常大的捆綁包；如果達到大小限制，請減少嵌入式資產。
-在TextPack中匯出的醒目提示使用Marked的醒目提示JSON格式。 請參閱[Reading Mode](Reading_Mode.html) ，瞭解如何建立和匯出重點摘要。
- Marked Share可在Direct、Mac App Store、Setapp和Marked Pro版本中使用。 無需單獨訂閱即可發佈。
