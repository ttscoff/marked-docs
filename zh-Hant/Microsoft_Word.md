# <%= @title %>

Marked 把 Microsoft Word（`.docx`）檔案當成 Markdown 開啟，也可以把這份 Markdown 再匯出為 DOCX。

## 來回轉換 [round-trip]

開啟 DOCX 檔案後，Marked 會把標題、清單等帶樣式的文字轉成 Markdown。修訂和註解變成 CriticMarkup，螢光標示變成 `<mark>` 標籤。匯出為 DOCX 即可把文稿送回 Word，CriticMarkup 會變成修訂。

匯入和匯出、頁首和頁尾、數學式以及自訂 Word 樣式，請參閱[使用 DOCX](Working_With_DOCX.html)。
